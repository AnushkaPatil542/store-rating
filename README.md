# Store Rating Platform

A full-stack web application for managing stores and their ratings with role-based access for Admin, Store Owners, and Users.

 🚀 Live Demo

**Frontend:**
https://store-rating-sigma.vercel.app

**Backend API:**  
https://store-rating-0z6q.onrender.com

 ✨ Key Features

- User registration and JWT-based login
- Role-based access: Admin, User, Store Owner
- Admin dashboard for managing users and stores
- Store owners can view their store ratings
- Users can browse stores and submit ratings
- Users can update their ratings
- RESTful backend APIs
- Secure authentication and authorization

 🛠️ Tech Stack

**Frontend:** React.js, Vite, Axios, React Router  
**Backend:** Node.js, Express.js, Sequelize  
**Database:** TiDB Cloud (MySQL-compatible)  
**Authentication:** JWT  
**Deployment:** Vercel, Render, TiDB Cloud
